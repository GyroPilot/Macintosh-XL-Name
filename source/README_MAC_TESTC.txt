Macintosh XL Name - TEST BUILD C (October 6 2026)
NOT FOR RELEASE. For trying the mechanism on any Macintosh with System 7.

WHAT IS NEW IN C
Test B announced "Macintosh XL" on the network, but on the wrong socket (4). Real Macintoshes keep the model name on socket 253. Test C finds the socket the old model name was on and announces "Macintosh XL" on that same socket.

TO TEST
1. Take "Macintosh XL Name TEST B" out of the Extensions folder.
2. Drag "Macintosh XL Name TEST C" onto the System Folder icon and restart.
3. When the desktop appears, wait 30 seconds.
4. On the netatalk machine type:  nbplkup
   Look for the line  Performa 475:Macintosh XL  and the number after the colon.
5. Scan the network with the scanner: what is the line under this Macintosh?
6. Open "XL Name Log" at the top level of the startup disk and photograph it.

TO REMOVE
Drag it out of the Extensions folder and restart. Everything goes back.
