Macintosh XL Name - TEST BUILD A (October 5 2026)
NOT FOR RELEASE. For trying the mechanism on any Macintosh with System 7.

WHAT IT DOES
At startup it renames THIS Macintosh, whatever model it is, to "Macintosh XL", in memory only. It also swaps the machine picture for the Lisa "XL" icon. The System file is not modified.

TO TEST
1. Take the regular "Macintosh XL Name" out of the Extensions folder if it is there.
2. Drag "Macintosh XL Name TEST" onto the System Folder icon and restart.
3. Look at About This Macintosh: does it say "Macintosh XL"?
4. Look at this Macintosh in the network scanner from another machine: does the line under its name say "Macintosh XL"?

TO REMOVE
Drag it out of the Extensions folder and restart. Everything goes back.

The machine type that installers check is not changed.
