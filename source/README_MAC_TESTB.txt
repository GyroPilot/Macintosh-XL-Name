Macintosh XL Name - TEST BUILD B (October 5 2026)
NOT FOR RELEASE. For trying the mechanism on any Macintosh with System 7.

WHAT IS NEW IN B
Test A renamed this Macintosh in About This Macintosh, but the network still showed the old model name. Test B also re-announces the name on the network, and it writes a log file so we can see what happened.

TO TEST
1. Take "Macintosh XL Name TEST" (test A) out of the Extensions folder.
2. Drag "Macintosh XL Name TEST B" onto the System Folder icon and restart.
3. When the desktop appears, wait 30 seconds.
4. Scan the network from another machine (a fresh scan): what is the line under this Macintosh?
5. Open the file "XL Name Log" at the top level of the startup disk and photograph it.

TO REMOVE
Drag it out of the Extensions folder and restart. Everything goes back.
The log file can be thrown away.
